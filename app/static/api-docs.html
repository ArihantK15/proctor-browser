Getting Started

To use the API, you'll need an API key:

  1. Log in to the dashboard
  2. Go to Tools → API Keys
  3. Generate a new API key
  4. Include it in requests as the X-API-Key header

Example request

curl -H "X-API-Key: your_key_here" \
  https://app.procta.net/api/v1/exams

Available endpoints

  • GET /api/v1/exams — List exams
  • GET /api/v1/exams/{id} — Get exam details
  • GET /api/v1/exams/{id}/students — List enrolled students
  • GET /api/v1/exams/{id}/sessions — List exam sessions
  • GET /api/v1/exams/{id}/sessions/{key} — Get session details
  • GET /api/v1/students/{roll} — Get student details

Authentication

The public API uses X-API-Key authentication. Admin endpoints use Bearer JWT tokens. See the Swagger docs for per-endpoint requirements.
